# Writeup screenshots

Drop screenshots referenced by writeup Markdown here, using the filenames the
Markdown expects, e.g.:

- `secret-nmap.png`, `secret-nodejs.png`, `secret-gitlog.png`
- `gem-home.png`, `gem-burp.png`

In a writeup `.md`, reference them with a normal Markdown image and a path
relative to the site root:

```markdown
![nmap output](assets/images/writeups/secret-nmap.png)
```

The original Notion pages stored these as expiring Notion-hosted URLs, so they
could not be migrated automatically — re-add the PNGs here when you have them.
