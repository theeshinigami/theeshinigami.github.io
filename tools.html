ctf-autoflag.sh

Automated CTF service scanner & flag hunter. Supports 10 services: HTTP, FTP, SSH, SMB, Telnet, DNS, SMTP, MySQL, Redis, SNMP. Give it a target, a flag prefix, and it hunts for flags automatically.

bash ctf scanner enumeration
Download
Usage 
chmod +x ctf-autoflag.sh

# Basic usage
./ctf-autoflag.sh <service> <target_ip> <flag_prefix> [port] [options]

# Examples
./ctf-autoflag.sh http 10.10.10.1 flag
./ctf-autoflag.sh ftp 10.10.10.1 picoCTF 2121
./ctf-autoflag.sh ssh 10.10.10.1 HTB -u root -p toor
./ctf-autoflag.sh dns 10.10.10.1 ctf -d challenge.ctf

# List supported services
./ctf-autoflag.sh --list

# Detailed help for a service
./ctf-autoflag.sh --help-service http
